# Gear-Driven Robotic Gripper – Linkage Mechanism Design
## Project Overview
This project presents the design of a mechanically synchronized robotic gripper using spur gears and a multi-link mechanism.  
The gripper ensures symmetrical jaw motion using a gear-driven system, making it suitable for robotic pick-and-place applications.  
Designed using Autodesk Fusion 360.  

## Objective
- Achieve synchronized jaw motion
- Convert rotational motion into controlled gripping action
- Maintain compact footprint
- Design fully mechanical linkage (no electronics modeled)

## Mechanism Description
The system consists of:  
- Dual spur gears (24 teeth)
- Central drive gear
- Multi-bar linkage system
- Pivot joints
- Symmetric gripping arms

## Working Principle:
1. Input rotation applied to central gear  
2. Spur gears transmit motion  
3. Gears drive linkages  
4. Linkages convert rotation into jaw closing motion  
5. Both jaws move symmetrically  

## Key Design Features
- Fully constrained mechanism
- Symmetric motion transfer
- Compact gear housing
- Multi-pivot linkage system
- Clear motion path
- Clean assembly hierarchy
